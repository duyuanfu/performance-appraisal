## Why

原料中心需要一套线上化、规范化、可追溯的 WEB 评审管理系统，支持约 50 人规模的月度部门负责人绩效考核以及年度目标管理绩效（按项目）评审两大核心场景。建设该系统能够替代线下纸质和离散表格打分，实现指标灵活配置、专家在线查阅 PDF 申报材料即时评分、加权总分自动计算与排名，以及历史结果查询和导出归档。

## What Changes

- **系统框架与权限体系**：搭建基于 React + Spring Boot 的前后端分离架构，实现用户认证、基于 RBAC 的角色权限管理（管理员、中心领导、评审专家、被评价人员），支持一人多角色切换与项目回避规则。
- **月度绩效考核能力**：支持管理员创建考核批次、分配被考核人员与中心领导、配置指标与评价人权重；中心领导在线打分（支持暂存与提交）；系统按配置权重自动计算综合得分并支持排名与导出。
- **年度目标管理绩效评审能力**：支持管理员创建项目评审批次、录入/导入参评项目及其 PDF 材料和附件、分配评审专家；评审专家在线查阅 PDF 并按指标打分；系统自动汇总平均分与排名，支持历史查询与导出。
- **指标与权重配置能力**：提供月度考核与年度项目评审的默认指标与权重模板，支持管理员灵活新增、编辑指标及配置权重，并在保存时进行满分校验。

## Capabilities

### New Capabilities
- `user-auth`: 用户管理、身份认证、RBAC 角色权限体系（支持一人身兼多职与切换）。
- `metric-config`: 考核与评审指标库、评分标准、权重分配及校验规则配置。
- `monthly-appraisal`: 月度绩效考核全流程管理（批次创建、对象与领导配置、多领导加权评分、暂存/提交、自动汇总排名、个人结果查询与导出）。
- `annual-project-appraisal`: 年度目标管理项目评审全流程管理（项目与 PDF 材料管理、专家在线分屏预览材料打分、利益回避、综合得分汇总、排名与导出）。

## Impact

- **技术栈**：新建 Spring Boot 3 + MyBatis-Plus + MySQL 8.0 后端工程，以及 React 18 + Vite + Ant Design 前端工程。
- **文件存储**：服务器本地受控目录存储项目申报 PDF 文件，提供流式鉴权预览接口。
- **API 接口**：新增认证授权、用户管理、批次流程、指标配置、打分交互、报表汇总与 Excel 导出等 RESTful API。
