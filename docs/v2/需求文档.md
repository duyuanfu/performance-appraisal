# 绩效系统2.0

## 一、 新增角色：

新增系统管理员：账号管理，项目删除。已有的管理员负责创建评审项目，汇总数据，催办等，将之前的账号管理移交给系统管理员。

## 二、账户数据

使用《评审管理系统相关.xlsx》中的账号配置sheet。如果设计到用户数据表修改，请和我确认修改方案。

## 四、目标绩效任务评审（原年度项目评审）考核维度

现在细分为目标绩效任务评审和专项与创新任务评审两种。

### 1.目标绩效任务评审

#### 1.1 考核指标与权重配置的默认配置

完成度、完成质量、完成时效性，占比分别为30%，50%，20%。

#### 1.2 评分领导及权重配置

计算公式：综合得分=（中心主要领导评分*20%+分管领导评分*30%+其他中心领导评分*50%）*50%+正职评分*40%+代表评分*（即为评审专家）10%

得分系数=综合得分/所有项目平均分；
